# تمرین عملی: تصویر پس ‌زمینه در CSS

## هدف

ساخت یک بخش زیبا برای صفحهٔ وب با استفاده از تصویر پس‌زمینه در CSS.

## نیازمندی‌ها

1. یک تصویر طبیعت یا منظره انتخاب کنید.
2. تصویر باید تمام بخش اصلی صفحه را بپوشاند.
3. تصویر نباید تکرار شود.
4. یک عنوان و یک متن کوتاه در وسط صفحه قرار دهید.
5. یک دکمۀ **Learn More** اضافه کنید.
6. برای خوانایی بهتر متن، روی تصویر یک لایۀ تیره و نیمه‌ شفاف قرار دهید.
7. طرح را برای صفحه‌های کوچک و بزرگ مناسب بسازید.

## قوانین

- از HTML و CSS استفاده کنید.
- ظاهر نهایی باید منظم و خوانا باشد.
- انتخاب تصویر، رنگ‌ ها و طراحی به عهدۀ خودتان است.
- از روی تصویر نمونه الهام بگیرید؛ لازم نیست دقیقاً همان طرح را کپی کنید.
